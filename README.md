## 两条搭建路径：宝塔面板与官方 LEMP 脚本

### 路径 A：宝塔面板，适合第一次碰 Linux

系统镜像选 Debian 12 或 Ubuntu 22.04 LTS，这两个版本的社区资料最多，遇到报错好搜。付款后几分钟到十几分钟会收到开通邮件，里面有 IP、root 密码和面板地址。

SSH 连上去，先把初始密码改掉：

bash
ssh root@你的服务器IP
passwd


然后到宝塔官网复制 Linux 面板的通用安装命令，粘贴执行。装完终端会输出面板地址、用户名和初始密码，浏览器打开登录。

进面板后到软件商店装 LNMP 环境，Nginx、MySQL、PHP 按宝塔推荐的版本走。接着建站：

- 域名填主域名和 www 两个
- 数据库账号用随机生成，别用 root
- 打开强制 HTTPS，证书选 Let's Encrypt 免费证书
- 数据库主机保持 localhost，表前缀改成自定义字符
- 管理员邮箱用 Gmail 这类国际邮箱，国内邮箱收 WordPress 邮件容易进垃圾箱

站点建好后用宝塔的一键部署装 WordPress，几分钟跑起来。主题选 Astra 或 GeneratePress 这类轻量的，插件先用 WP Rocket 做缓存、RankMath 做 SEO，别一上来装十几个。

安全五项顺手做掉：改掉宝塔默认的 8888 端口、开 SSH 密钥登录、装 Fail2ban、设置每日自动备份到异地、在 PHP 配置里禁用 passthru、system 这类危险函数。这五件事花不了二十分钟，能挡掉大部分扫站脚本。

### 路径 B：官方 LEMP 自动脚本，一条命令装完 WordPress

这条路前面中文教程基本没提。RackNerd 官方博客在 2025 年 9 月发过一篇 AlmaLinux 上自动安装 WordPress 的教程，附一个免费的 bash 脚本，打包成 zip 放在官方博客的资源目录里。

前提条件有四个：VPS 装的是 AlmaLinux 并且已经配好 LEMP 栈、域名已经解析到 VPS 的 IP、有 root 或 sudo 权限、装了 nano 编辑器（`dnf install nano -y`）。

操作流程：

1. 从 RackNerd 官方博客那篇文章里下载脚本压缩包，解压出脚本内容
2. 在服务器上 `nano autowp.sh`，把脚本粘进去，`CTRL+O` 保存、`CTRL+X` 退出
3. `chmod +x autowp.sh` 赋予执行权限
4. `sh autowp.sh` 运行，按提示依次填数据库 root 密码、新建数据库用户的凭据、博客域名、安装目录、Nginx 站点配置

脚本会自动完成系统更新、创建 WordPress 数据库、下载并安装 WordPress、配置 Nginx 站点模板、调整 SELinux 权限、优化 Nginx 和 PHP 参数。跑完之后浏览器打开域名，进入 WordPress 安装向导，设站点标题、建管理员账号、选主题就完事。

比宝塔省事的地方在于它直接把 Nginx 站点模板和 SELinux 权限一起处理了，这两步手动做最容易卡住。代价是它对系统有要求（AlmaLinux + LEMP），不像宝塔那样什么发行版都能装。

### 域名解析与上线前的收尾

到域名注册商后台加两条 A 记录：主机记录 `@` 指向 VPS 的 IP，主机记录 `www` 也指向同一个 IP（或者给 www 加一条 CNAME 指向主域名）。TTL 用默认值，一般十分钟左右全球生效。

解析生效后再去申请 SSL 证书，顺序反了证书验证会失败。

## 按站点类型选套餐

写博客、放技术笔记、做个人作品集，1 GB 足够，这是最主流的选择，也是大多数人该买的那一档。

企业官网要装联系表单、SEO 插件、缓存插件、统计代码，2 GB 给 PHP 和 MySQL 留的余量更舒服，高峰时段不容易 502。

跑 WooCommerce 或跨境自建站，4 GB 起步。电商插件多、数据库读写频繁、还有支付和订单流程，4 GB 是底线，流量起来之后升到 6 GB。

手上要放 3 到 5 个中小站点，6 GB 或 8 GB 更划算。纯学习、测试环境、练 Docker，1 GB 就够，随时可以重装。

“买大不买小”在这是个误区。RackNerd 支持按比例补差价升级，先买 1 GB 跑两周，不够再升，总成本一样，还避免了为一台空转的机器多付钱。
